## 在 Cutline 里使用

1. 进入工作台 → 左侧「导入媒体」或音频面板「导入音乐」。
2. 在音频面板「背景音乐」里选择刚导入的音频（列表只显示音频素材）。
3. 调整音乐音量、开启自动闪避；对白出现时音乐会自动压低。
4. 导出时勾选「包含背景音乐」。
